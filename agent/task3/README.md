# 任务3：智能体工作流

本任务实现一个智能体工作流，能够结合DuckDuckGo搜索工具回答实时信息问题。

## 任务概述

智能体工作流是指多个智能体协同工作，通过特定的流程和规则完成复杂任务的系统。本任务实现了一个简单但完整的智能体工作流，包括问题分析、关键词提取、信息搜索和答案生成等环节。

## 实现方式

### 智能体工作流实现 (agent_workflow.py)

本任务的核心实现是`agent_workflow.py`文件，它包含以下主要功能：

- **问题分析**：分析用户输入的问题，理解问题意图
- **关键词提取**：从问题中提取关键词，用于搜索
- **信息搜索**：使用DuckDuckGo搜索工具获取相关信息
- **答案生成**：基于搜索结果生成最终答案
- **结果展示**：展示详细的搜索过程和最终答案

## 工作流程

智能体工作流的完整流程如下：

1. **用户输入问题**
   - 用户输入需要解答的问题
   - 系统接收并预处理用户输入

2. **问题分析**
   - 智能体分析问题的类型和意图
   - 判断是否需要搜索外部信息

3. **关键词提取**
   - 从问题中提取关键词
   - 优化关键词以提高搜索准确性

4. **信息搜索**
   - 使用DuckDuckGo搜索工具获取相关信息
   - 过滤和排序搜索结果

5. **答案生成**
   - 基于搜索结果生成答案
   - 确保答案的准确性和相关性

6. **结果展示**
   - 展示搜索过程和结果
   - 提供最终的答案

## 环境配置

### 1. 安装依赖包

使用pip安装所需的依赖包：

```bash
pip install -r requirements.txt
```

### 2. 配置API Key

确保在项目根目录（`d:\Desktop\智能体方向\`）下创建或编辑`.env`文件，添加以下内容：

```
DEEPSEEK_API_KEY=your_api_key_here
```

## 运行程序

### 运行智能体工作流

```bash
python agent_workflow.py
```

## 使用说明

### 智能体工作流使用说明

1. 确保您已在.env文件中正确配置了DEEPSEEK_API_KEY
2. 程序启动后会显示初始化状态和功能说明
3. 输入您的问题（建议是需要实时信息的问题，如"今天北京的天气怎么样？"、"请帮我找一下最新的人工智能新闻"等）
4. 智能体将自动执行完整工作流：分析问题→提取关键词→搜索信息→生成回答
5. 程序会显示详细的搜索结果和最终的AI回答
6. 输入"quit"、"退出"或"exit"结束程序

## 代码结构

### 主要组件

1. **环境设置**
   - `setup_safe_encoding()`: 设置安全的编码环境
   - `load_environment()`: 加载环境变量和API Key
   - `create_llm()`: 创建LLM实例

2. **搜索工具**
   - `duckduckgo_search()`: 使用DuckDuckGo搜索信息

3. **智能体工作流**
   - `analyze_question()`: 分析用户问题
   - `extract_keywords()`: 提取关键词
   - `search_information()`: 搜索相关信息
   - `generate_answer()`: 生成最终答案

4. **用户交互**
   - `run_agent_workflow()`: 运行智能体工作流
   - `safe_print()`: 安全打印函数

### 关键技术点

1. **编码处理**
   - 使用`setup_safe_encoding()`处理不同终端的编码问题
   - 使用`safe_print()`确保中文正确显示

2. **API调用**
   - 使用DeepSeek API进行文本生成
   - 使用DuckDuckGo API进行信息搜索

3. **工作流管理**
   - 模块化设计，每个步骤都有独立的函数
   - 错误处理和异常管理

## 故障排除

如果您遇到问题，请检查以下几点：

1. **API Key是否正确**：确保您输入的API Key与Deepseek平台上的一致
2. **网络连接是否正常**：确保您可以访问Deepseek API服务器和DuckDuckGo
3. **API调用额度是否足够**：检查您的Deepseek账号是否有足够的调用额度
4. **依赖包是否安装正确**：运行 `pip install -r requirements.txt` 确保所有依赖都已安装
5. **编码问题**：如果遇到中文显示问题，尝试在支持UTF-8的终端中运行程序
