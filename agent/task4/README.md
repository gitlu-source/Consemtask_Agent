# 任务4：多智能体系统

本任务实现一个多智能体系统，展示多个智能体如何协作完成复杂任务。

## 任务概述

多智能体系统是由多个智能体组成的集合，这些智能体通过相互协作、通信和协调来完成单个智能体难以解决的复杂问题。本任务实现了一个完整的多智能体系统，包括不同类型的智能体、通信机制和协作模式。

## 实现方式

### 多智能体系统实现 (MultiAgent/)

本任务的核心实现是`MultiAgent`文件夹，它包含以下主要组件：

- **主控制程序** (`main.py`): 协调和管理多个智能体的运行
- **智能体模块** (`agents/`): 包含多种不同功能的智能体实现
- **文档存储** (`documents/`): 存储智能体处理所需的文档
- **向量数据库** (`chroma_db/`): 存储文档的向量表示，用于检索相关内容

### 智能体类型

系统实现了多种不同类型的智能体，每种智能体专注于特定任务：

1. **计算智能体** (`calculate_agent.py`): 专门处理数学计算和逻辑推理
2. **搜索智能体** (`search_agent.py`): 负责信息检索和知识查询
3. **分析智能体** (`analysis_agent.py`): 进行数据分析和问题解析
4. **生成智能体** (`generation_agent.py`): 生成文本和创意内容
5. **协调智能体** (`coordination_agent.py`): 协调其他智能体的工作，分配任务

## 系统架构

### 整体架构

多智能体系统的整体架构如下：

```
┌─────────────────────────────────────────────────────────────┐
│                    主控制程序 (main.py)                     │
└─────────────────────┬───────────────────────────────────────┘
                      │
          ┌───────────┴───────────┐
          │                       │
┌─────────▼─────────┐   ┌────────▼────────┐
│   智能体模块      │   │   向量数据库    │
│   (agents/)      │   │   (chroma_db/)  │
└─────────┬─────────┘   └────────┬────────┘
          │                       │
          └───────────┬───────────┘
                      │
          ┌───────────▼───────────┐
          │     文档存储         │
          │    (documents/)      │
          └─────────────────────┘
```

### 智能体通信机制

智能体之间的通信采用以下机制：

1. **消息传递**：智能体之间通过结构化消息进行通信
2. **任务队列**：使用任务队列管理系统中的任务分配
3. **共享状态**：通过共享状态存储中间结果和系统状态
4. **事件驱动**：基于事件的异步通信模式

### 协作模式

系统支持多种协作模式：

1. **主从模式**：一个主智能体协调多个从智能体
2. **平等协作**：所有智能体平等参与任务完成
3. **层级结构**：智能体按照层级关系组织和工作
4. **动态团队**：根据任务动态组建智能体团队

## 环境配置

### 1. 安装依赖包

使用pip安装所需的依赖包：

```bash
pip install -r requirements.txt
```

### 2. 配置API Key

确保在项目根目录（`d:\Desktop\智能体方向\`）下创建或编辑`.env`文件，添加以下内容：

```
DEEPSEEK_API_KEY=your_api_key_here
```

## 运行程序

### 运行多智能体系统

```bash
cd MultiAgent
python main.py
```

## 使用说明

### 多智能体系统使用说明

1. 确保您已在.env文件中正确配置了DEEPSEEK_API_KEY
2. 进入MultiAgent目录
3. 运行main.py启动多智能体系统

6. 系统会自动分析任务并分配给合适的智能体
7. 观察智能体之间的协作过程
8. 获取最终结果

## 故障排除

如果您遇到问题，请检查以下几点：

1. **API Key是否正确**：确保您输入的API Key与Deepseek平台上的一致
2. **依赖包是否安装正确**：运行 `pip install -r requirements.txt` 确保所有依赖都已安装
3. **向量数据库是否正确初始化**：检查chroma_db目录是否存在并包含必要文件
4. **文档是否正确加载**：检查documents目录中是否有相关文档
5. **智能体是否正确注册**：确保所有智能体都在主控制程序中正确注册
