# 任务2：调用API实现有上下文记忆的对话程序

本任务实现一个基于DeepSeek API的对话程序，具有上下文记忆功能，能够记住之前的对话内容，提供连贯的对话体验。

## 任务概述

本任务使用LlamaIndex框架和DeepSeek API实现一个智能对话程序，通过ChatMemoryBuffer组件维护对话历史，使AI能够记住之前的对话内容，提供更加连贯和智能的对话体验。

## 实现方式

### 对话程序实现 (chatbot_with_llamaindex.py)

本任务的核心实现是`chatbot_with_llamaindex.py`文件，它包含以下主要功能：

- **环境变量加载**：从.env文件中加载DeepSeek API密钥
- **LLM实例创建**：创建DeepSeek大语言模型实例
- **记忆功能实现**：使用ChatMemoryBuffer维护对话历史
- **对话引擎创建**：创建带有系统提示词的对话引擎
- **交互式对话**：提供用户友好的交互式对话界面

## 系统架构

### 整体架构

对话程序的整体架构如下：

```
┌─────────────────────────────────────────────────────────────┐
│                    对话程序                                │

                      │
          ┌───────────┴───────────┐

┌─────────▼─────────┐   ┌────────▼────────┐
│   DeepSeek LLM    │   │   记忆缓冲区    │

          │             └────────┬────────┘

          │         │   对话引擎         │
```

### 关键组件

1. **DeepSeek LLM**
   - 使用DeepSeek API提供的大语言模型
   - 配置了温度、最大令牌数等参数
   - 设置了API基础URL

2. **记忆缓冲区**
   - 使用ChatMemoryBuffer维护对话历史
   - 设置了令牌限制以防止请求过大
   - 自动管理对话上下文

3. **对话引擎**
   - 使用SimpleChatEngine创建对话引擎
   - 配置了系统提示词，要求AI展示思考过程
   - 集成了LLM和记忆缓冲区

4. **用户交互界面**
   - 提供简单的命令行交互界面
   - 支持中英文输入
   - 提供退出命令

## 环境配置

### 1. 安装依赖包

使用pip安装所需的依赖包：

```bash
pip install -r requirements.txt
```

### 2. 配置API Key

确保在项目根目录（`d:\Desktop\智能体方向\`）下创建或编辑`.env`文件，添加以下内容：

```
DEEPSEEK_API_KEY=your_api_key_here
```

## 运行程序

### 运行对话程序

```bash
python chatbot_with_llamaindex.py
```

## 使用说明

### 对话程序使用说明

1. 确保您已在.env文件中正确配置了DEEPSEEK_API_KEY
2. 运行`chatbot_with_llamaindex.py`启动对话程序
3. 程序会显示初始化状态和功能说明
4. 输入您的问题或对话内容
5. AI会展示思考过程并给出回答
6. 程序会记住之前的对话内容，提供连贯的对话体验
7. 输入"退出"、"quit"或"exit"结束程序

## 代码结构

### 主要组件

1. **环境变量加载**
   - `load_environment()`: 加载环境变量和API Key
   - 验证API Key是否存在

2. **LLM实例创建**
   - `create_llm()`: 创建DeepSeek LLM实例
   - 配置模型参数和API设置

3. **记忆功能实现**
   - `create_chat_engine()`: 创建带有记忆功能的对话引擎
   - 配置记忆缓冲区和系统提示词

4. **用户交互**
   - `run_chatbot()`: 运行对话程序
   - 处理用户输入和AI响应

### 关键技术点

1. **API调用**
   - 使用DeepSeek API进行文本生成
   - 处理API响应和错误

2. **记忆管理**
   - 使用ChatMemoryBuffer维护对话历史
   - 自动管理上下文长度

3. **系统提示词**
   - 设计系统提示词，要求AI展示思考过程
   - 提高回答的可解释性

## 故障排除

如果您遇到问题，请检查以下几点：

1. **API Key是否正确**：确保您输入的API Key与Deepseek平台上的一致
2. **网络连接是否正常**：确保您可以访问Deepseek API服务器
3. **API调用额度是否足够**：检查您的Deepseek账号是否有足够的调用额度
4. **依赖包是否安装正确**：运行 `pip install -r requirements.txt` 确保所有依赖都已安装
5. **编码问题**：如果遇到中文显示问题，尝试在支持UTF-8的终端中运行程序
